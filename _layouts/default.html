{%- comment -%} Jekyll & Plaid: Markdown on GitHub Pages, in Carnegie Mellon's web template with the Carnegie Mellon Web Kilt. Settings, all optional, in _config.yml: title the site's name, in the header and footer description a line under the name cmu.roof red (default), gray or white cmu.kit the Web Kilt release to load (default 0.8.30, the one the theme is tested with) cmu.parent the office or site this one belongs to (title and url): first in the breadcrumbs, and the description links to it cmu.nav the pages in the navigation, in order, by file name; without it, every page with a title, by nav_order in its front matter (a page with nav_secondary: true goes in the menu only, after the tabs) cmu.footer office (defaults to title), address (a list of lines), phone, email (a Contact Us link) and links (title and url) cmu.github_link false leaves out the menu's link to the site's GitHub repository cmu.nav_links other sites to list after the pages in the navigation (title and url; tab: true makes one a tab after the pages instead of a menu-only link) cmu.preview the link preview image (default images/preview.jpg, when the site has one) cmu.preview_alt its alt text (default "'s home page.") Markdown's ## headings get the template's rule-top line, as section headings do in the Web Kilt. Each page's description, or the site's, becomes its meta description.
